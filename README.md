## How to Use

1. **Open the website:**
   - Simply open `index.html` in any modern web browser

2. **Navigate:**
   - Use the navigation menu to jump to different sections
   - Click the "Learn More" button to scroll to event details

3. **View location:**
   - Check the embedded Google Map in the Location section
   - Click "View on Google Maps" for full map experience
